# 💻 Projeto de Atividade Extensionista

Este projeto foi desenvolvido como parte de uma atividade extensionista, em parceria com estudantes do curso Técnico em Informática do IFMS.

O objetivo do projeto é colocar em prática conhecimentos em desenvolvimento web.

## 🚀 Tecnologias utilizadas

* HTML
* CSS

📚 Um projeto desenvolvido com aprendizado, colaboração e muita prática!
