# 💻 Projeto de Atividade Extensionista

Uma Single Page para apresentação de currículo e perfil profissional, desenvolvida em uma atividade extensionista com estudantes do curso Técnico em Informática do IFMS.

O objetivo do projeto é colocar em prática conhecimentos em desenvolvimento web.

## 🚀 Tecnologias utilizadas

* HTML
* CSS

📚 Um projeto desenvolvido com aprendizado, colaboração e muita prática!
